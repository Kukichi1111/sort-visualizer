# sort-visualizer

7種類のソートアルゴリズムを同じ初期配列で同時に動かし、動き方と操作回数を並べて比べられるブラウザアプリです。

すべてのソートが同じステップ数ずつ進むので、「同じ手間をかけたときにどこまで進んでいるか」がそのまま見えます。

## 収録しているソート

| ソート | 計算量（平均） | 補足 |
| --- | --- | --- |
| バブルソート（通常） | O(n²) | 交換がなくても最後まで走査する |
| バブルソート（改良） | O(n²) | 1パスで交換がなければ打ち切る |
| 選択ソート | O(n²) | |
| 挿入ソート | O(n²) | 退避中の値 `v` を補助段に表示 |
| マージソート | O(n log n) | 左右の部分配列 `L` `R` を補助段に表示 |
| クイックソート | O(n log n) | ピボットは区間の中央。再帰の代わりに明示的なスタックで処理 |
| ヒープソート | O(n log n) | `build heap` / `extract` のフェーズを表示 |

## 操作

| 操作 | 内容 |
| --- | --- |
| ▶ 再生 / ❚❚ 一時停止 | 全ソートをまとめて再生・停止。全部終わった後に押すと最初からやり直す |
| リセット | 現在の設定で初期配列を作り直す |
| 速度 | 1秒あたりのステップ数（対数スケール）。右端は MAX（描画が追いつく限り進める） |
| おすすめ | O(n log n) のソートが約20秒で終わる速度に合わせる |
| 自動加速 | O(n log n) のソートがすべて終わったら、1秒ごとに速度を2倍にする（O(n²) を最後まで待たなくて済む） |
| n | 要素数（8〜10000） |
| 初期配列 | ランダム / 昇順 / 逆順 / ほぼ整列済み / 重複が多い |
| シード | 乱数のシード。同じシードなら同じ初期配列になる。🎲 でランダムに変更 |

## 画面の見方

各パネルの下に、そのソートの操作回数が表示されます。

- **比較**: 要素どうしの比較
- **交換**: 2要素の入れ替え
- **代入**: 配列への書き込み（マージソートのコピーや挿入ソートのずらし）
- **退避・書き戻し**: 挿入ソートで一時変数 `v` に値を出し入れした回数
- **計**: 上の合計。これが「1ステップ」の数で、全ソートはこの値が揃うように進みます

バーの色の意味は次のとおりです。

| 色 | 意味 |
| --- | --- |
| 黄 | 比較 |
| 赤 | 交換 |
| 水色 | コピー元 |
| 緑 | コピー先 |
| 紫 | ピボット |
| 青 | 確定した位置 |
| 茶 | 補助配列 |
| 暗い背景 | 処理中の範囲 |

## ファイル構成

```
index.html           画面の骨組み
style.css
js/
  main.js            UI とイベント処理
  player.js          再生ループ（全パネルを同じステップ数ずつ進める）
  panel.js           ソート1つ分の表示
  renderer.js        canvas への描画
  tracer.js          配列操作を記録しつつ実行し、操作回数を数える
  input.js           初期配列の生成
  rng.js             シード付き乱数（mulberry32）
  sorts/
    index.js         ソートの一覧と表示設定
    bubbleBasic.js / bubbleOptimized.js / selection.js /
    insertion.js / merge.js / quick.js / heap.js
```

## ソートを追加するには

各ソートはジェネレータ関数で、`Tracer` の操作（`compare` / `swap` / `copy` / `save`）を1回呼ぶたびに `yield` します。表示用の情報（`setRange` / `setPivot` / `setPointer` / `markSorted` / `setPhase`）はステップを消費しないので `yield` しません。

```js
export function* mySort(t) {
  const A = t.A;
  // ...
  yield t.compare(i, j);
  if (A[i] > A[j]) yield t.swap(i, j);
}
```

作ったら `js/sorts/index.js` の `SORTS` に追加します。補助配列を使う場合は `usesAux: true`、O(n log n) のソートなら `fast: true`（自動加速の判定に使われます）を付けてください。
